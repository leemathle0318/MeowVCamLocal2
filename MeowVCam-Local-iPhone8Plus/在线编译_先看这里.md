# 用 GitHub 网页编译本地视频混音版

电脑只需要浏览器和解压软件。实际编译运行在 GitHub 的 macOS 机器上。
此配置仅编译 iPhone 8 Plus 的本地视频源码（视频原声加现场麦克风），没有 OBS 版，也没有手机测试 App。
这次加入编译配置，但没有实际运行 GitHub Actions，没有生成或验证 `.deb`。
安装环境时直接使用云端 Xcode 自带的 iOS SDK，不再调用 install-sdk 下载 SDK。

## 1. 建立仓库

登录 https://github.com ，打开 https://github.com/new 。
Repository name 填 `MeowVCamLocal`。
公开仓库（Public）使用标准 Actions runner 免费，但源码会公开。
若不想公开源码，选 Private，并查看自己账户的 Actions 可用额度。
勾选 Add a README file，点击 Create repository。

## 2. 上传解压后的内容

先把源码 ZIP 解压，进入 `MeowVCam-Local-iPhone8Plus` 文件夹。
打开仓库的 Code 页面，点 Add file → Upload files。
把工程文件夹里面的全部文件和文件夹拖进上传区域，然后提交到默认分支。

必须上传 `.github`、`core`、`tweak`、`scripts`、`layout` 等文件夹及 Makefile、control 等文件。
不要只上传 ZIP，也不要把整个外层 `MeowVCam-Local-iPhone8Plus` 文件夹拖进去。
仓库最外层应直接能看到 `Makefile` 和 `.github`。
编译配置在仓库中的正确路径是 `.github/workflows/build.yml`。

如果上传后看不到 `.github`：点 Add file → Create new file，文件名填写
`.github/workflows/build.yml`，用记事本打开解压包中的同名文件，将全部内容复制到网页并提交。
如果 Makefile 出现在额外一层工程文件夹里，请先按上述布局重新上传到仓库根目录。

## 3. 开始云端编译

点仓库顶部 Actions，左侧选 Build iPhone 8 Plus DEB。
如果出现启用 Actions 的提示，按页面提示启用。
点 Run workflow，选默认分支，再点绿色 Run workflow。
刷新后打开刚出现的编译任务，等待完成。
本配置只在点击 Run workflow 时运行；上传本身不会启动编译。

## 4. 下载真正的安装包

编译任务显示绿色对勾后，打开该任务页面，向下找到 Artifacts。
点击 `MeowVCamLocal-iPhone8Plus-DEB` 下载结果 ZIP，再解压得到 `.deb`。
`MeowVCamLocal-build-logs` 是日志，里面没有安装包。
此配置设置结果保存七天，成功后及时下载。

## 5. 出现红叉时

点开红色步骤，复制错误附近的日志，或下载 `MeowVCamLocal-build-logs` 后发给我。
若设置环境失败，页面仍会保存已有的日志；没有 DEB 文件时不会假装编译成功。
如果没有 Run workflow 按钮，先检查 `.github/workflows/build.yml` 是否位于默认分支的正确路径。

编译成功只代表源码编译和打包通过，音量按键、视频画面、原声、系统私有接口和
iOS 15.0–16.6.1 兼容性仍需要在实际设备上确认。这个源码原型还不能承诺安装即用。

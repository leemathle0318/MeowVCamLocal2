# 本地视频替换摄像头：iPhone 8 Plus 源码修订版 0.4.0

这是需要重新编译的源码，不是已验证的成品 DEB。0.4 尚未在本环境完成 iOS 编译和真机确认。
仅包含本地视频版，没有 OBS，也没有手机测试 App。目标为 arm64 Rootless / iPhone 8 Plus。
iOS 15.0–16.6.1 是待验证范围。

## 本次声音行为

只选择一个视频，画面替换摄像头，视频自带的原声与现场麦克风一起送入音频采集。
不会要求另外选择音频，不关闭麦克风，也不用通过扬声器播放视频再收音。
代码先复制现场麦克风 PCM，再叠加同一时刻的视频 PCM；原始麦克风样本不被修改。
视频无音轨、尚未准备好、缓存暂时欠载时，麦克风声音仍保留。
两路默认保持原增益，相加峰值超过 PCM 范围时饱和限幅，可能产生削波失真。

## 触摸与窗口修订

用户反馈旧版选择视频后触摸失效，实体按键仍可使用。代码检查发现：旧版在导入期间
保留全屏透明 UIWindow，且再次按音量组合键不能关闭它。这符合窗口拦截触摸的表现，
但没有设备日志，不能把它认定为唯一原因。

- 新增“从相册选择视频”，使用系统 PHPicker，仅显示视频。
- 保留“文件”选择和输入已有路径的方式。
- 选完或取消立即隐藏窗口、关闭触摸拦截，不等待导入结束或窗口动画回调。
- 窗口打开时，再次按“音量加 → 音量减”会强制关闭窗口。
- 导入在后台完成，可再次按组合键打开菜单取消导入或停止替换。
- 空窗口两秒后关闭；导入结果提示八秒后自动关闭。
- 解码移至独立后台进程 MeowVCamLocalDecoder；不是手机 App。
- 系统媒体进程只接收固定大小的画面/声音缓存，不再使用 AVAssetReader 打开视频。
- 画面转换移至后台队列，最多一项待处理；采集回调不等待转换。
- 转换超过半秒仍未返回时，本次会话停用替换；后续是否恢复需手动操作。
- 安装或升级重置选择和启用状态，避免旧配置立即重现异常。

## 怎么使用

安装、通过多巴胺重启用户空间后，先按音量加，再在 1.5 秒内按音量减。
菜单中的“从相册选择视频”是本次新增入口。选择后菜单立即关闭，视频后台导入。
相册中只存在于 iCloud 的视频需要先下载；系统提供的相册选择器在 SpringBoard 中的
实际表现尚未验证，若打不开或返回错误，请保留错误信息。

导入使用 1 MiB 缓冲分块复制到 `/var/mobile/Media/MeowVCamLocal/`，供后台进程读取。
不把整个视频读入内存，但需要足够磁盘空间。旧副本保留，可以在不用后用 Filza 清理。
输入手机已有的可读取路径则直接读取，不复制。

菜单保存时默认开启循环，视频结束后重新从头播放画面和原声，麦克风持续参与混音；循环衔接可能有停顿。
没有文件大小或时长的拒绝条件。源格式需要是 iOS 能解码的视频，优先 MP4/MOV、H.264 + AAC。

为降低 iPhone 8 Plus 负载，默认处理后画面长边 720、最高 30 fps，可在配置调整长边至 1280。
这是处理分辨率/帧率限制，与文件大小和时长限制不同。视频方向、HDR、长时间资源使用仍待验证。

## 兼容范围和重要行为

当前仍尝试静态参考包中的系统私有采集接口，并在运行时检查方法类型。
私有接口签名、菜单窗口、相册服务、后台工具启动、视频和声音接入均未完成本次真机验证。
不能保证编译成功后就适配某个直播 App。

后台数据未到达、转换太慢、输出超过 1920×1920、格式不支持或替换已停用时，
当前代码会继续传递原始摄像头数据。首次开始或循环的短暂空档也可能显示原摄像头画面。
音频只替换受支持的 16-bit signed PCM / 32-bit float PCM、单/双声道、8–192 kHz，
单次回调不超过 4096 帧；不支持的格式继续传递原麦克风数据，此时视频原声可能未接入。无音轨的视频保留麦克风声音。
目标 App 必须允许麦克风并启动音频采集；App 自己关闭采集或将音频静音时，插件不能保证仍有声音。

配置文件：`/var/mobile/Library/Preferences/com.meowmeow.vcam.local.plist`。
字段为 enabled、mode（local）、source、loop、videoLongEdge、audioMode（mix）。
本修订默认并固定使用混音行为，没有单独音频文件选择或关闭麦克风的选项。
后台传输文件为 `/var/mobile/Library/Caches/MeowVCamLocal/frames-v3.bin`，大小固定，
不会随源视频变长而增加；不要在运行期间手动截断或替换它。

PCM 缓存、双来源混音、16-bit 麦克风在视频静音时的精确保留、峰值限幅、

更换源时映射隔离的 C 检查通过，脚本语法和 plist 可解析。
